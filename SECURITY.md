# Security

Report a vulnerability in private. Do not open a public issue.

- [GitHub security advisory](https://github.com/paymog/bend-kit/security/advisories/new)
- paymahn1@gmail.com

`crypto`, `jwt`, `oauth2`, `webhooks`, and `wire` handle secrets and signatures. Several packages load native libraries (OpenSSL, libsqlite3, libz, libzstd, brotli). Proofs do not cover the `.c` and `.js` effects.

## Supported versions

The latest version of each package on the Bend hub. Older versions are not patched. A publish is permanent.
